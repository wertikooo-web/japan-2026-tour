# Japan 2026 Tour

Одностраничный сайт авторского путешествия по Японии: Токио, Кавагучико, Фудзи, Эносима и Камакура.

**Сайт:** https://wertikooo-web.github.io/japan-2026-tour/

## Что есть на сайте

- маршрут на 9 дней с переключением глав;
- отдельная глава восхождения на Фудзи;
- карточки проводников, условия участия и список вещей;
- иллюстрации и видео для дней маршрута;
- переключатель языков: русский, румынский и английский;
- общая кнопка звука для видео;
- кнопка заявки, открывающая письмо на `wertikooo@gmail.com`;
- адаптация для телефона и компьютера.

## Структура проекта

```text
.
├── index.html       # весь сайт: разметка, стили и логика
└── assets/          # изображения, постеры и видео для глав
```

Проект не требует сборки: сайт работает как статическая HTML-страница. Стили используют Tailwind CDN, а шрифты загружаются из Google Fonts.

## Открыть локально

Скачайте репозиторий и из его папки запустите:

```bash
python -m http.server 8000
```

Затем откройте в браузере:

```text
http://localhost:8000
```

Можно открыть `index.html` и двойным кликом, но локальный сервер надёжнее для проверки видео и браузерных ограничений на звук.

## Как обновлять сайт

### Тексты и маршрут

Все тексты находятся в `index.html`.

Главы маршрута расположены в блоках с атрибутом:

```html
<article class="chapter" data-chapter="...">
```

Кнопки переключения дней находятся выше, в списке `.day-tab`. При добавлении дня нужно создать и кнопку, и соответствующую главу.

### Переводы

Внизу `index.html` есть объект `languagePacks` и функция `applySiteLanguage()`.

Для нового видимого текста добавьте перевод в блоки `en` и `ro`. Верхнее меню переводится отдельной логикой внутри `applySiteLanguage()`.

### Изображения и видео

Файлы лежат в `assets/`. Видео для глав подключаются скриптом в конце `index.html`.

Рекомендации:

- используйте имена файлов латиницей без пробелов;
- для видео предпочтителен MP4 с H.264 для изображения и AAC для звука;
- добавляйте постер JPG для тяжёлых роликов;
- перед публикацией проверяйте сайт и на телефоне, и на компьютере.

### Звук видео

Браузеры запрещают включать звук автоматически. Поэтому звук запускается только после нажатия общей кнопки в шапке. Её состояние применяется к текущей открытой главе и сохраняется при переключении дней.

## Публикация

Репозиторий опубликован через GitHub Pages. После коммита в ветку `main` GitHub Pages обновит сайт автоматически.

Если новая версия не видна сразу, сделайте жёсткое обновление страницы:

- Windows: `Ctrl + F5`
- macOS: `Cmd + Shift + R`
